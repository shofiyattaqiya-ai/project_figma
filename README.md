## 📌 Latar Belakang Proyek
Aplikasi pengelola berkas seperti Google Files sangat krusial untuk manajemen media harian. Proyek ini berfokus pada penyempurnaan alur pencarian hingga pengiriman berkas foto agar pengalaman pengguna (*User Experience*) menjadi lebih efisien, cepat, dan intuitif.

## 🔄 Alur Interaksi Prototipe (User Flow)


<img width="1015" height="442" alt="image" src="https://github.com/user-attachments/assets/c664d4e7-5411-4473-a0c3-1cf6998ef5b5" />


1. **Halaman Utama (Home):** Titik awal akses kategori media, berkas terbaru, dan status penyimpanan.
2. **Pencarian Cepat (Search & Filters):** Kolom penelusuran interaktif dengan kata kunci dan filter media.
3. **Hasil Penelusuran (Search Results):** Menampilkan daftar berkas foto yang relevan secara presisi.
4. **Pratinjau Media (Preview Mode):** Tampilan *fullscreen* resolusi tinggi untuk memeriksa detail foto.
5. **Opsi Berbagi (Sharing Options):** Menu *pop-up bottom sheet* untuk mengirimkan foto ke aplikasi lain (WhatsApp, Instagram, Quick Share).
